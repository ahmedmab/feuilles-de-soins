# Feuilles de soins CNOPS / CNSS — application web

Application 100 % statique (un seul fichier) pour remplir la partie « assuré(e) » des
feuilles de soins CNOPS et CNSS, en français et/ou en arabe, puis télécharger le PDF complété.

- Aucun serveur, aucun envoi de données : tout se passe dans le navigateur.
- Cinq formulaires : CNOPS Soins Maladie, CNOPS ALD, CNOPS Dentaire, CNSS Soins Maladie,
  CNSS Soins Dentaires.
- Le PDF produit est le formulaire officiel ; seule la partie assuré est complétée.

Site : https://ahmedmab.github.io/feuilles-de-soins/

*Projet personnel, sans affiliation avec la CNOPS ni la CNSS.*
